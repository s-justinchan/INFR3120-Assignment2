# INFR 3120 - Assignment 2

This README file will document external resources used within the project.

## Bootstrap v5.0

In this assignment, **Bootstrap** was required for use within the pages. I used the _navbar_ from Boostrap which was explained during the lectures. It is an edited version of it, with the navbar's color being changed to align with the text and page background, which has a linear gradient. This navbar is applied on every page through the _header.ejs_ partial file. 

The _footer_ was made to be similar to the rest of the page design and header. It uses classes from the navbar/header applied to it,
so that the style is consistent across the whole page.

Link to _navbar_ documentation: https://getbootstrap.com/docs/5.0/components/navbar/
